# Devpost Documentation Package

This folder standardizes the repository evidence for the OpenCV AI Competition 2026 submission.

## Files

- [`../../DEVPOST-SUBMISSION.md`](../../DEVPOST-SUBMISSION.md) — main Devpost write-up draft.
- [`TESTING.md`](TESTING.md) — reproducible local test and judge-demo instructions.
- [`DEMO-SCRIPT.md`](DEMO-SCRIPT.md) — short video/run-of-show script.
- [`EVIDENCE-MATRIX.md`](EVIDENCE-MATRIX.md) — mapping from Devpost requirements and judging criteria to repository evidence.

## Remaining participant tasks

1. Capture 3–5 final screenshots and write captions.
2. Record and publish the demo video, maximum five minutes.
3. Paste the video URL into the Devpost form; the live endpoint URLs are already documented in the submission draft.

Do not place credentials, `.env` files, private keys, raw user evidence, or model binaries in the public repository.
